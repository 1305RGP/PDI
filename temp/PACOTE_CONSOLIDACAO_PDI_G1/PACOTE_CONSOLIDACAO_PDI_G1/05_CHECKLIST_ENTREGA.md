# Checklist de recebimento

## IA A
- [ ] Revisão técnica de schemas
- [ ] Matriz CA → schema/fixture/teste
- [ ] Relatório de testes e limitações
- [ ] Patch candidato, se necessário
- [ ] Execução real separada de análise estática

## IA B
- [ ] Revisão de governança/estado
- [ ] Matriz de decisões e estados
- [ ] Pendências que exigem proprietário
- [ ] Patch de estado proposto, não aplicado
- [ ] Confirmação de baseline canônica preservada

## Consolidação final
- [ ] Achados deduplicados
- [ ] Divergências verificadas na fonte primária
- [ ] Todos os critérios rastreados
- [ ] Testes não executados marcados `NOT_RUN`
- [ ] Decisões humanas isoladas
- [ ] Um único patch candidato
- [ ] Instruções de aplicação e rollback
- [ ] Sem aprovação automática do Gate G1
