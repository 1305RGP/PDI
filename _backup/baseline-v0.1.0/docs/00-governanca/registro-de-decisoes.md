# Registro de Decisões

**Versão:** 0.1.0  
**Estado:** aberto e controlado.

| ID | Decisão | Estado | Observações |
|---|---|---|---|
| DEC-001 | O projeto utiliza a pasta `PDI` como raiz inicial. | APROVADA | Pasta informada como vazia pelo usuário. |
| DEC-002 | Os Contratos 01 a 05 compõem a baseline conceitual inicial. | APROVADA | Aprovados explicitamente na conversa; controles ainda não implementados. |
| DEC-003 | O Núcleo padroniza controles, não uma arquitetura única para todos os produtos. | APROVADA | Arquitetura local deve ser justificada por ADR. |
| DEC-004 | Não alterar repositórios existentes nem instalar/conectar ferramentas nesta etapa. | APROVADA | Restrição operacional da inicialização. |
| DEC-005 | Estrutura inicial documental será criada antes de implementar orquestração. | APROVADA | Pacote documental v0.1.0. |
| DEC-006 | Ferramentas só serão consideradas compatíveis após inspeção e teste no ambiente real. | APROVADA | Documentação pública não basta. |
