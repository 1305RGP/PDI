# Ciclo APDF

**Versão:** 0.1.0

Ciclo obrigatório:

1. **Construir:** produzir o incremento autorizado.
2. **Provar:** executar as verificações definidas para esse incremento.
3. **Diagnosticar:** interpretar falhas e divergências com evidências.
4. **Feedback:** registrar aprendizado e decisões necessárias.
5. **Incremento de Valor:** ajustar a entrega dentro do escopo aprovado.
6. **Validar:** confirmar critérios de aceite e registrar o resultado.

O ciclo não autoriza ignorar gates, alterar testes aprovados unilateralmente ou declarar sucesso sem evidências. Se houver expansão de escopo, voltar ao processo formal de mudança.
